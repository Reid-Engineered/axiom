Axiom — UI mockups, round 1

Screens 1–4 at full size, plus variation studies for navigation, home, and the study session.

Flat spec sheet — nothing is clickable. Each screen sits next to its annotations. Pan and zoom freely on this canvas.

What I assumed
  • Tauri, multi-platform — so: no traffic lights, no vibrancy, no platform-specific chrome. A neutral desktop shell that reads correctly on macOS, Windows, and Linux.
  • Balanced density: 13px body, 38px toolbar, 232px sidebar.
  • Equations are typeset and static in this round; the visualization surface is a labelled placeholder.
  • Calculus II / Shell Method is the worked example throughout.
Decisions worth arguing with
  • “Workspace” over “Collection” — it carries the sense of an environment you work inside.
  • No permanent tab bar in a workspace. Overview is the only destination; Learn/Concepts/Resources are reached from content.
  • Progress is shown as one thin unlabelled bar, never a percentage. Mastery is a named state (New → Mastered), never a number — see 4a.
  • The home screen leads with one sentence of remembered context — “what you were doing” beats “how you're doing”.
